# Contributing to Spokenbase Community

Thank you for helping improve Spokenbase Community.

Before starting substantial work:

1. read `AGENTS.md` and `CURRENT_MILESTONE.md`;
2. open an issue describing the user need and proposed public capability;
3. confirm the work belongs in the Community product;
4. keep changes focused and include the required tests and documentation.

Contributors must have the right to submit every contribution. Do not submit
proprietary code, code copied from the commercial repository, generated code
with unclear ownership, or third-party material with incompatible terms.

Substantial contributions may require a contributor agreement that permits the
project to maintain AGPL Community releases and separate commercial licensing.
The contributor process will be documented before such contributions are
merged.

New application source files use:

```text
SPDX-License-Identifier: AGPL-3.0-only
```

Independently reusable protocol or SDK files use Apache-2.0 only when the file
or package explicitly declares that license.
