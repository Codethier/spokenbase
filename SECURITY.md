# Security Policy

Recordings, transcripts, summaries, organization data, and provider
credentials are sensitive.

Please do not disclose a suspected vulnerability in a public issue. Use the
private vulnerability-reporting feature in the public GitHub repository when
available. If that channel is unavailable, ask a maintainer for a private
reporting channel without including exploit details.

Include the affected revision, deployment shape, impact, and a minimal
reproduction. Do not include real customer recordings, transcripts, secrets,
or personal data.

Milestone 0 is a development bootstrap and does not yet represent a supported
production release.
